# sincelast

A changelog tool for tiny teams: merged PRs become draft release notes, you tidy them up, and one click publishes a public "what's new" page, RSS feed and embeddable widget.

This repo is also a loop-engineering experiment — the tool is built by a chain of small agent loops.

- [PRD.md](PRD.md) — what we're building
- [PLAN.md](PLAN.md) — the loops and milestones
- [CLAUDE.md](CLAUDE.md) — rules every loop follows
- [docs/adr/](docs/adr/) — architecture decisions
- [loops/](loops/) — one prompt per loop
